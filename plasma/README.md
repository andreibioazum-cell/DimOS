# DimOS Plasma — рабочий стол на KDE Plasma 6.8 (только ПК)

Это новая ветка DimOS: вместо самописного ядра — обычный Linux-дистрибутив
с **KDE Plasma 6.8** (Wayland-сессия, X11 в Plasma 6.8 уже не поддерживается).
Эмулятора и QEMU-сценария в этой ветке нет: сборка рассчитана на установку
на реальный ПК (UEFI и BIOS).

## Что внутри

| Часть | Что сделано |
| --- | --- |
| Обои | `plasma/wallpaper/dimos-wallpaper.png` — сгенерированы ИИ, 16:9 |
| Панель | Нижняя панель в стиле Windows: слева меню «Пуск» (Kickoff), по центру — запущенные окна, справа — трей и часы |
| Тема | Breeze Dark; акцент `#00b4ff`; плавающая панель со скруглёнными углами; размытие фона (KWin blur); скругление окон |
| Консоль | Konsole с профилем DimOS (схема Breeze, шрифт Noto Sans Mono) |
| Шрифт | Noto Sans 10 pt |
| Браузер | Firefox (`firefox` в `packages.x86_64`) |
| Вход | SDDM с Wayland-сессией Plasma |
| Файлы | Dolphin, терминал Konsole, Ark, Kate |
| Сеть и звук | plasma-nm, plasma-pa |

## Состав

```
plasma/
  README.md                       этот файл
  build-iso.sh                    сборка ISO через archiso (на Arch Linux)
  wallpaper/dimos-wallpaper.png   обои
  archiso/
    packages.x86_64               пакеты: Plasma 6.8, Firefox и т.д.
    airootfs/
      etc/sddm.conf.d/dimos.conf  вход в Plasma (Wayland)
      etc/skel/.config/           настройки панели, темы и обоев для новых пользователей
      usr/share/wallpapers/DimOS/ обои в формате Plasma
```

## Сборка

Нужен Arch Linux (или Arch-контейнер) с `archiso`:

```
sudo pacman -S archiso
cd plasma && sudo ./build-iso.sh
```

Скрипт копирует базовый профиль `releng`, подставляет наши пакеты и файлы и
запускает `mkarchiso`. Готовый ISO появится в `plasma/out/`.

## Честные ограничения

- **Эта конфигурация не собиралась и не загружалась в этой среде.** В песочнице
  нет доступа к зеркалам Arch и KDE, поэтому проверка сборки и вид панели
  на экране ещё не подтверждены.
- Скрипт проверяет версии Plasma перед сборкой и остановится, если
  `plasma-desktop` не 6.8.x.
- Раскладка панели задаётся через `plasma-org.kde.plasma.desktop-appletsrc`.
  Внешний вид после первого входа может потребовать мелкой подстройки.
- Старое ядро DimOS (`src/`, `build-linux.sh`, `run-linux.sh`, QEMU-скрипты)
  в этой ветке пока не удалено: его можно убрать отдельным шагом.

## Статус (честно)

- **Архитектура: x86-64.** Образ собирается archiso с `arch="x86_64"`, ядро и
  пользовательское окружение 64-битные. Старое 32-битное ядро DimOS
  (`src/`, i686) в эту ветку не переносилось и остаётся в `main`.
- **ISO не собран и не загружен.** В среде разработки нет доступа к зеркалам
  Arch и KDE, поэтому списки пакетов и конфиги не проверены сборкой.
- **v86 в браузере.** Стандартный v86 эмулирует только 32-битный x86 без
  long mode и не загрузит ни Arch, ни Plasma. Нужен форк с x86-64 или
  локальная виртуалка (QEMU/KVM, VirtualBox).
