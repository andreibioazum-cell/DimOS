# DimOS Images (TGA Format)

Эта папка содержит изображения в формате TGA для операционной системы DimOS.

## Содержимое

### Основные изображения
- **desktop.tga** - Черный экран 320x200 (базовый шаблон для рабочего стола)
- **dimos_logo.tga** - Логотип DimOS
- **title.tga** - Заголовок "DIMOS" в центре экрана
- **gradient.tga** - Градиент от синего к белому
- **line.tga** - Диагональная линия

### Иконки приложений (32x32)
- **files_icon.tga** - Иконка Files (Файловый менеджер)
- **snake_icon.tga** - Иконка Snake (Змейка)
- **mines_icon.tga** - Иконка Mines (Сапер)
- **paint_icon.tga** - Иконка Paint (Рисование)
- **calc_icon.tga** - Иконка Calculator (Калькулятор)
- **music_icon.tga** - Иконка Music (Музыка)
- **about_icon.tga** - Иконка About (О системе)
- **terminal_icon.tga** - Иконка Terminal (Терминал)

### Шрифты
- **font8x8.tga** - Шрифт 8x8 (тестовое изображение с сеткой)
- **font8x8_full.tga** - Полный шрифт 8x8 из BIOS (все символы из font8x8.py)
- **font8x8.txt** - Описание шрифта
- **font_optimized.h** - Супер-оптимизированный шрифт из BIOS (C header, 760 bytes)
- **font_optimized.bin** - Binary версия оптимизированного шрифта
- **font_optimized.tga** - TGA версия оптимизированного шрифта
- **font_ttf_8x8.h** - Шрифт из TTF (DejaVu Sans) в C формате (760 bytes)
- **font_ttf_8x8.bin** - Binary версия TTF шрифта
- **font_ttf_8x8.tga** - TGA версия TTF шрифта (128x48)

## Формат

Все изображения в формате TGA (TARGA):
- Разрешение: 320x200 (кроме иконок 32x32)
- Глубина цвета: 24 бита (RGB)
- Формат: несжатый true-color
- Совместим с VGA режимом 13h (320x200, 256 цветов)

## Шрифт

Шрифт `font8x8_full.tga` содержит все символы из исходного шрифта DimOS (font8x8.py):
- Символы: 0x20 - 0x7E (95 символов)
- Размер: 8x8 пикселей на символ
- Расположение: 16 символов в строке, 8 строк

## Использование

Эти изображения можно использовать:
1. Как текстурные ресурсы для DimOS
2. Как эталонные изображения для тестирования
3. Для документации проекта

## Конвертация

Изображения были созданы с помощью:
- ImageMagick (для базовых изображений)
- Python (для шрифта и текста)

Формат TGA выбран как простой несжатый формат, совместимый с большинством графических библиотек.
