# fonts/ — настоящий TTF-шрифт рабочего стола

Положите сюда **любой TrueType-шрифт** под именем `font.ttf` — сборка
скопирует его на загрузочный том как `FONT.TTF`, а ядро при старте само
разберёт таблицы TrueType (`cmap`, `glyf`, `loca`, `head`, `maxp`),
растеризует контуры глифов и будет рисовать им весь текст системы.
Никакой предварительной конвертации не нужно: парсер и растеризатор
живут прямо в ядре (`src/kernel/font_ttf.c`).

Для VBE-экрана ядро строит **нативный 16×16 raster** каждого глифа прямо из
TrueType-контура. Каждый пиксель получает уровень покрытия 0…16 по сетке
4×4 подпикселей; `gfx.c` смешивает только край штриха с уже нарисованным
фоном. Поэтому буквы остаются чёткими, без pixel-doubling и без размытия:
сглаживание есть лишь на контуре. Отдельная 8×8 таблица оставлена для
VGA/RGB565 fallback и совместимости с маленьким логическим canvas.

```
cp мой-шрифт.ttf fonts/font.ttf
make iso          # пересобрать образы — и весь DimOS в новом шрифте
```

Если файла нет или он не читается, ядро тихо откатывается на шрифт
видео-BIOS — сломать систему плохим шрифтом нельзя.

## Требования к файлу

- **Формат:** TrueType с контурами `glyf` (обычный `.ttf`).
  OpenType/CFF (`.otf` с PostScript-контурами) не поддерживается.
- **Размер:** файл должен помещаться в предзагруженное окно диска
  рядом с ядром — примерно **80 КБ**. Точную границу считает и
  проверяет `build-linux.sh`. Большой шрифт легко ужать до ASCII:

  ```
  pip install fonttools
  pyftsubset большой-шрифт.ttf --unicodes=U+0020-007E \
      --no-hinting --output-file=fonts/font.ttf
  ```

## Предпросмотр без загрузки ОС

`make font` собирает `tools/font_preview.c` вместе с тем же самым
кодом ядра и печатает нативные 16×16 VBE-глифы так, как их нарисует DimOS:

```
make font                                  # весь набор
bin/dimos-font-preview fonts/font.ttf ПРИВЕТ   # отдельные буквы
```

Если утилита пишет `OK: DimOS will boot with this font` — шрифт
заработает и в ядре: это один и тот же код.

## Шрифт по умолчанию

В репозитории лежит `font.ttf` — **Inter** (вес 350, оптический размер 14),
урезанный до ASCII: обычный не-пиксельный шрифт интерфейса, ~28 КБ.
Он выбран потому, что остаётся читаемым в клетке 8×8: большая высота
строчных букв и открытые «внутренности» у `a`, `e`, `6`, `8`, `9`.
Лицензия — в `LICENSE-Inter.txt` (SIL Open Font License 1.1).
Замените файл своим — больше ничего менять не нужно.
