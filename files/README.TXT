DimOS 2.0 + DimXfce

The x86-64 kernel uses a 1920x1080 VBE XRGB framebuffer at up to
60 FPS, with RGB565 and VGA compatibility fallbacks.

The mouse logo at the top left opens the Whisker menu with every app.
Right click on the wallpaper does the same, xfdesktop style.
The ^ button in a window title rolls it up into a slat, the little
monitor in the dock shows and hides the desktop, and the power button
on the panel restarts DimXfce.

Cheesy Balls keeps the mascot fed: NYAM eats a cheese ball with
ketchup, twelve of them earn one big BURP, Cook more fries a refill.

DIR lists the real FAT12 files on this disk.
TYPE README.TXT reads this file.
DEL removes only a user file for the current session.
KERNEL.BIN is protected so deleting files can never stop DimOS booting.
